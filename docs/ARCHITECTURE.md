Frontend Architecture & Stack:

Framework: Next.js (App Router) to ensure fast routing and structured components.

Styling: Tailwind CSS combined with a custom CSS global grain/noise overlay to give the UI texture.

Animations: GSAP & @studio-freight/lenis for buttery smooth scrolling. Framer Motion for micro-interactions (hover states, modal pops, Kanban card dragging).

Visual Centerpiece: @react-three/fiber for a lightweight, abstract geometric background element in the hero section to secure the Awwwards feel.
