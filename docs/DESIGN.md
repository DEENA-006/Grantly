Visual Foundation: Calm, off-white/light gray background. Strictly avoid heavy, generic AI-style gradients.

Accent Color: A single electric accent color (e.g., #FF3366 or #4F46E5) reserved strictly for primary interactive actions (Apply/Save).

Typography: A high-contrast mix. Use a massive Display Serif (e.g., Playfair Display) for headers, and a clean Mono font for metadata, tags, and amounts.

Copywriting: Concise and direct. Remove all fluffy instructions.

Frictionless UX: Search and filter inputs use thin underlines instead of heavy boxes.

Dynamic Feedback: Real-time visual feedback (e.g., a green checkmark morphing from a button) when a scholarship is saved.

Loading States: Implement skeleton loaders for the initial data fetch to prevent layout shifts. Spinners are strictly reserved for the final "Submit" action.
